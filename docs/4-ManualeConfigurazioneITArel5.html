Manuale di configurazione

  • Scopo: In questo manuale trovi tutte le informazioni necessarie per configurare myAssistente5 e sfruttarne al meglio le potenzialità.
  • Prerequisiti: L’eseguibile di myAssistente5 per il tuo sistema operativo,
    oppure, in alternativa, i file Python myAssistente.py e (opzionale, per usare il linguaggio AIML) aiml_parser.py, con Python installato sulla tua macchina (multipiattaforma).
  • Riferimenti: (1) Manuale installazione, (2) Manuale utente.

I nomi di tutti i comandi possono essere modificati nel file lang_XX.json e potrebbero quindi differire da quelli indicati in questo manuale. Leggi di seguito per maggiori dettagli.

📁 Dove sono collocati i file

Il file trattato in questo manuale si trova all’interno della cartella _dati/.

  • _dati/config.json: Impostazioni principali.

File config.json

Nota: Se il file config.json è assente, il sistema ti avvertirà e ne genererà uno predefinito all’avvio. Se è presente ma corrotto, verrà rinominato in config.json.bak e ne verrà creato uno nuovo.

In caso di cambio lingua, il sistema memorizzerà l’informazione in config.json e salverà un backup della configurazione precedente in config.json.bak.

La configurazione completa può essere effettuata direttamente dall’interfaccia utente di myAssistente usando il comando configura. Consulta il (2) Manuale utente per le istruzioni.

All’interno di questo file puoi configurare diversi parametri. Aprilo con un editor di testo:

Prima parte: Configurazioni avatar

{
  "nome_avatar": "Alice",
  "nome_utente": "Emanuele",
  "lingua": "it",
  "avatar_gruppi": { 
    "positivo": [ "sorridente", "soddisfatto", "coniglio" ],
    "negativo": [ "triste", "dispiaciuta", "piangente" ],
    "generico": [ "sorridente", "soddisfatto", "coniglio", "agenda" ]
  },
  "avatar_random": "generico",
  "avatar_iniziale": "benvenuto",
  "avatar_finale": "ciao.mp4",
  "frase_finale": "Ci vediamo presto!",
  "avatar_colori": {
    "default": "#6c7086",
    "benvenuto": "#89b4fa",
    "sorridente": "#a6e3a1",
    "soddisfatto": "#fab387",
    "triste": "#f38ba8",
    "magazziniere": "#cba6f7",
    "ciao": "#94e2d5"
  },

Nel (1) Manuale installazione abbiamo già visto come modificare i nomi dell’assistente e dell’utente tramite interfaccia grafica.
Qui puoi anche configurare le immagini dell’avatar. I nomi devono corrispondere ai file presenti in _dati/asset/avatar/. Se non specifichi l’estensione, verrà cercato automaticamente un file .jpg; in caso contrario, indica l’estensione come nell’esempio ciao.mp4.

Apri la cartella _dati/asset/avatar/, inserisci nuovi file o rinomina quelli esistenti per farli corrispondere alle impostazioni. Nei tag “avatar” puoi inserire direttamente il nome dell’immagine oppure il nome di un gruppo di immagini.

Nell’esempio, come immagine iniziale viene usato benvenuto.jpg. Per l’immagine casuale viene usato il gruppo generico, che sceglie a caso tra sorridente.jpg, soddisfatto.jpg, coniglio.jpg e agenda.jpg. Puoi creare quanti gruppi desideri e assegnare a ciascuno le immagini che preferisci.

Come immagine finale, nell’esempio è impostato il video ciao.mp4.
Quando l’immagine non è presente nella cartella, l’assistente mostra un quadrato. In avatar_colori puoi definire il colore da usare per ogni avatar mancante.

In frase_finale puoi impostare la frase pronunciata dall’avatar alla chiusura di myAssistente.
Il parametro lingua (gestito automaticamente dal programma) indica la lingua iniziale all’avvio.

Seconda parte: Configurazioni audio/microfono

Impostazioni audio per la sintesi vocale (Text‑to‑Speech) e il riconoscimento vocale (Speech‑to‑Text). Solitamente i parametri predefiniti sono adeguati, ma puoi migliorare la qualità audio modificandoli.

Nota importante: qui si imposta la lingua usata da Google Speech per la pronuncia dell’assistente. Il valore viene configurato automaticamente, ma puoi modificarlo per esigenze regionali (es. en-GB invece di en-US).

Attenzione: I dati vocali vengono elaborati tramite le API di Google Speech. Non utilizzare il microfono se desideri una privacy totale. 
  "tts_config": {
    "engine": "auto",
    "rate": 150,
    "volume": 0.9,
    "pitch": 50,
    "voice_gender": "auto"
  },
  "stt_config": {
    "soglia_rumore": 200,
    "sample_rate": 16000,
    "max_secondi": 10,
    "silenzio_secondi": 0.5,
    "lingua": "it-IT"
  },

L’impostazione "lingua": "it-IT" è fondamentale per la corretta pronuncia tramite le API di Google. Se altoparlanti e microfono funzionano correttamente, non è necessario modificare gli altri parametri.

Se utilizzi un avatar femminile e il sistema seleziona una voce maschile, puoi modificare "voice_gender": "auto".

Terza parte: Parametri AI (API e provider)

Questa sezione è opzionale: puoi collegare myAssistente a un’Intelligenza Artificiale esterna. Se il sistema non trova una risposta internamente (memoria, risposte fisse, AIML), invece di rispondere non ho capito inoltrerà la domanda all’IA.

Imposta "enabled": true e inserisci i parametri e la chiave API forniti dal tuo provider IA.

  "ai_config": {
    "enabled": false,
    "provider": "openai",
    "api_key": "",
    "model": "gpt-3.5-turbo",
    "temperature": 0.7,
    "max_tokens": 500,
    "fallback_to_ai": true
  },
Attenzione: L’integrazione AI richiede una connessione Internet, a meno che tu non utilizzi un modello IA installato localmente. Per la massima privacy, lascia "enabled": false.

In fondo al file, trovi anche l'impostazione delle priorità da dare all'assistente per cercare le risposte quando non le trova internamente:

  "risposta_config": { "modalita": "aiml_then_ai" },

`aiml_then_ai` per cercare prima negli AIML; quando l'assistente non trova riscontri, passa all'IA (default).
`aiml_only` per usare solo AIML; quando non trova riscontri, dichiara: "non ho capito..."
`ai_only` usa solo IA esterna; ignora i file AIML.

Quarta parte: Risposte fisse

Le risposte fisse sono risposte immediate e preconfigurate a domande specifiche. Di solito si preferisce usare i file AIML, ma puoi usare questa sezione se vuoi dare priorità assoluta a determinate risposte rispetto alla memoria, agli AIML e all’IA.

  "risposte_fisse": {
    "grazie": "Prego, {nome_utente}!",
    "ciao": "Ciao, {nome_utente}!",
    "come stai": "Sto benissimo, grazie!",
    "autore": "Il mio autore è Emanuele Cassani",
    "author": "My author is Emanuele Cassani",
    "credit": "©2026, Emanuele Cassani www.steppa.net/cassani"
  },

  "risposta_config": { "modalita": "aiml_then_ai" },

Qui puoi anche configurare la priorità tra AIML interni e IA esterna. L’impostazione predefinita aiml_then_ai indica che il sistema consulta prima gli AIML e, se non trova risposte, passa all’IA.

Quinta parte: Alias dei comandi

Puoi aggiungere o modificare qualsiasi alias dei comandi utilizzati da myAssistente. Per ogni comando puoi definire più parole alternative: la prima apparirà nell’interfaccia grafica, le altre saranno accettate come sinonimi.

Esempio: "cerca": ["cerca", "ricerca", "prendi"] Nel file lang_it.json puoi impostare la dicitura del pulsante (es. “cerca…”).

Il sistema utilizza normalmente le impostazioni del file lang_XX.json, ma gli alias definiti qui rimangono attivi anche se l’utente cambia lingua.

Non è necessario tradurre/modifcare questi comandi se il fle della lingua selezionata (esempio: lang_it.json) è presente.

  "alias_comandi": {
    "dammi":    ["trova", "dimmi", "mostrami", "visualizza"],
    "apri":     ["apri", "lancia", "avvia", "esegui", "metti"],
    "cerca":    ["cerca", "ricerca"],
    "elenca":   ["elenca", "lista", "mostra tutto"],
    "configura":["configura", "impostazioni", "settings", "preferenze"],
    "aiuto":    ["aiuto", "help", "comandi"],
    "esci":     ["esci", "chiudi", "arrivederci", "quit", "exit"],
    "impara":   ["impara", "apprendi", "inserisci"],
    "ricorda":  ["ricorda", "memorizza", "salva"],
    "modifica": ["modifica", "cambia", "aggiorna"],
    "elimina":  ["elimina", "cancella", "rimuovi"],
    "copia":    ["copia", "duplica", "copy"]
  },

Ultima parte: Shortcut

Gli shortcut sono i pulsanti di scelta rapida presenti nell’interfaccia utente. Puoi modificare sia il nome del pulsante sia il comando associato.

È sufficiente indicare l’etichetta del pulsante e il comando da eseguire. Se il comando termina con uno spazio (es.: "comando": "ok "), verrà inserito nel campo di input in attesa di ulteriori parametri; se non termina con uno spazio, verrà eseguito immediatamente.

Puoi aggiungere quanti pulsanti desideri, ma ne verranno mostrati al massimo quattro contemporaneamente.

  "shortcut": [
    { "etichetta": "Ho capito", "comando": "ok" },
    { "etichetta": "Estratto conto", "comando": "apri estratto conto" },
    { "etichetta": "Mail", "comando": "apri posta" },
    { "etichetta": "Browser", "comando": "apri web" }
  ],

Esempi:
Il pulsante “Ho capito” interrompe l’assistente durante la lettura di testi lunghi. Puoi anche creare shortcut per comandi specifici del sistema operativo Windows (vedi DocENGrel5.x‑WindowsUsefulCommands.md).
