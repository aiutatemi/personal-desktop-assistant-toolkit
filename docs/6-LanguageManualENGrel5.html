(6) Language Configuration Manual

This manual explains how to configure the language settings of myAssistente to make the most of its features. The distribution packages always include Italian and English, but additional languages can be added by downloading the ready‑made files from the project repository.

  • Purpose: This manual shows how to add a new language or modify an existing one.
  • Prerequisites: The myAssistente executable for your operating system,
    or alternatively the Python files myAssistente.py and (optional, for AIML support) aiml_parser.py, with Python installed on your machine (multiplatform).
  • References: (1) Installation Manual, (2) User Manual, (4) Configuration Manual, (5) Memory Configuration Manual.
The distribution packages always include the Italian and English languages. You can add more by translating the files or downloading them from the project repository.

All command names can be customized in the lang_XX.json file and may therefore differ from those shown in this manual. For details, refer to the (4) Configuration Manual.

📁 File locations

The files described in this manual are located inside the _dati/ folder.

  • _dati/lang_*.json: Localization files.

The lang.json file

Note: If the system cannot find any lang_XX.json file, it will fall back to the default language: Italian.

When the language is changed, the system stores the information in config.json and saves a backup of the previous configuration in config.json.bak.

The language can be selected directly from the myAssistente user interface using the buttons under Language. The system automatically detects the languages available inside the _dati/ folder and makes them selectable.

File names follow the pattern lang[CODE].json, where [CODE] is the standard language code. Examples: langIT.json, langEN.json, langDE.json. All terms can be customized inside these files. Open them with a text editor.

First section: Speech recognition language

  "lingua_stt": "en-US",

This is the language used by the assistant for pronunciation and speech recognition through Google Speech. It is important to specify the region as well (e.g., en-GB or en-US). The same information is also present in the config.json file, used by the system if no language file is found.

Second section: Command names

  "alias_comandi": {
    "dammi":    ["give", "show", "get"],
    "apri":     ["open", "launch", "start"],
    "cerca":    ["search", "find", "look"],
    "elenca":   ["list", "all"],
    "configura":["configure", "settings", "config"],
    "aiuto":    ["help"],
    "esci":     ["exit", "quit", "close", "bye"],
    "impara":   ["learn", "teach"],
    "ricorda":  ["remember", "save", "store"],
    "modifica": ["modify", "edit", "update", "change"],
    "elimina":  ["delete", "remove", "erase"],
    "copia":    ["copy"]
  },

On the left is the system command name; on the right are the names that will appear when clicking the corresponding button in the interface. The system name in Italian will always work: the names you add are additional alternatives.

You may specify multiple names for the same command or none at all (e.g., "esci": []). If a name is duplicated by mistake, only the first one will be used.

Third section: User interface labels

  "titolo_finestra":  "EN Assistant – {nome_avatar}",

  "label_comandi":        "COMMANDS",
  "panel_dammi":          "give ...",
  "panel_apri":           "open ...",
  "panel_cerca":          "search ...",
  "panel_media":            "search media",
  "panel_elenca":         "list memory",
  "panel_configura":      "configure",
  "panel_aiuto":          "help",
  "panel_esci":           "exit",
  "panel_sep_memoria":    "── MANAGE MEMORY ──",
  "panel_impara":         "learn",
  "panel_ricorda":        "remember ...",
  "panel_ricorda_img":    "remember image",
  "panel_modifica":       "modify ...",
  "panel_elimina":        "delete ...",
  "panel_copia":          "copy ...",
  "label_shortcut":       "SHORTCUTS",
  "label_lingua":         "LANGUAGE",
  "btn_invia":            "Send",

These are all the labels and button names used in the myAssistente interface. Important: if you change the button label, clicking it will still insert the first command configured in alias_comandi. To keep them consistent, use the same term.

Example command:

  "alias_comandi": {
    "dammi":    ["give", "show", "get"],
  }

Example corresponding button:

  "panel_dammi": "show..."

In this example, the button will display show..., but the dialog will show give.

Fourth section: Exclusions

These articles are removed from the user’s sentence so the system can correctly interpret commands.

  "articoli": [ "the", "a", "an", "of", "in", "on", "at", "to", "for", "with", "by", "from", "into" ],

Example: Apri la posta (“Open the mail”). If not configured otherwise (see (7) AIML Manual), the command would not be recognized. With this list, the article la is ignored, and the command becomes simply apri posta.

Final section: Localize program messages

Here you can configure all the messages used by the program. Important: modify only the values on the right — the keys on the left must never be changed.

  "aiuto_testo":          "Type 'manuals' to open the manuals\nCommands: give...

If you need a line break, use \n rather than inserting a manual newline.

A single misplaced comma can break the entire .json file. If you have Python installed, you can validate it with:

python -m json.tool lang_it.json

Alternatively, you can ask an AI to check it by writing:

Check this JSON file, fix any errors and return it to me
