(1) Manuale installazione

  • Scopo: Questo manuale ti guida nella prima installazione del tuo myAssistente.
  • Prerequisiti: Il pacchetto ZIP con l'eseguibile di myAssistente per il tuo sistema operativo,
    oppure in alternativa: i file Python myAssistente.py e (opzionale per usare linguaggio AIML) aiml_parser.py con Python installato sulla tua macchina (multipiattaforma).
  • Sezioni: Installazione, Primo avvio del programma, Provalo
Scarica tutti i file necessari dal repository GitLab del progetto Assistente.
Le lingue italiano e inglese sono incluse nei pacchetti Windows e Linux. Se ti servissero lingue aggiuntive (15 lingue pronte all’uso), scarica il file lang_XX.json dalla cartella localization-file dello stesso repository GitLab.
Anche alcuni esempi di file AIML sono inclusi; file aggiuntivi in italiano si trovano nella cartella aiml-file dello stesso repository o si può usare qualsiasi file standard AIML facilmente reperibile in rete.

Procedura di installazione

L’applicazione myAssistente è portatile (portable application), può essere avviata da qualsiasi posizione, dal desktop o da una chiavetta USB.

Windows

Scarica e decomprimi myAssistente[last release]windows.zip
Avvia myAssistente.exe

Linux

Scarica e decomprimi myAssistente[last release]linux.zip
Avvia myAssistente

Python

Scarica myAssistente_[last release].py
Scarica il motore opzionale AIML aiml_parser.py
Scarica la cartella completa _dati/
Assicurati che la tua installazione Python includa tutte le dipendenze richieste (vedi file requirementsITA.txt e README)
Posiziona myAssistente_[last release].py, il file aiml_parser.py e la cartella _dati/ nella stessa directory
Avvia myAssistente_[last release].py

Tutti i Sistemi Operativi

Opzionale: scarica e inserisci eventuali file lingua aggiuntivi lang_XX.json nella cartella _dati (lo stesso luogo dove si trovano lang_it.json e lang_en.json) ed eventuali file AIML nella cartella _dati/aiml/[lingua]/.

Per personalizzare la lingua predefinita e altri parametri, fai riferimento al (2) Manuale utente. Numerosi manuali che spiegano il linguaggio AIML sono presenti in rete; i pochi parametri opzionali che si possono aggiungere per myAssistente sono descritti nel (6) Manuale AIML.

Struttura file:

myAssistente   <- .py, .exe o senza estensione per linux
aiml_parser.py <- necessario solo per utenti python
    _dati/
        config.json
        memory.json
        memory.json.bak
        langIT.json <- lingua presente di default
        langEN.json <- lingua presente di default
        langXX.json <- altre lingue
        asset/      <- i tuoi file personali saranno salvati qui
            avatar/ <- immagini e video avatar
            manuals/ <- manuali myAssistente HTML
        aiml/       <- AIML file opzionali
            IT/     <- AIML file per italiano
                saluti.aiml
            EN/     <- AIML file per inglese
                greetings.aiml
            XX/     <- crea cartella per AIML nella tua lingua

Primi passi

Nel (2) Manuale utente trovi le istruzioni passo-passo per la configurazione.
  • 1) Lingua — dopo aver seguito le istruzioni precedenti, la lingua dovrebbe essere corretta.
  • 2) Nome utente e assistente — come far apparire il vostro nome utente e un nome per la vostra assistente.
  • 3) Addestrare l'assistente DATI: istruzioni per memorizzare un dato e poi chiedere all'assistente di aprirlo.
  • 4) Addestrare l'assistente LINK: istruzioni per memorizzare un link e poi chiedere all'assistente di aprirlo.
  • 5) Pulsanti shortcut — istruzioni per personalizzare i pulsanti rapidi in basso a destra.
Nel (7) Manuale AIML trovi le istruzioni passo-passo per il linguaggio AIML.
  • 6) Migliorare la comprensione delle vostre domande:
    Dopo l'addestramento al punto 3, per ottenere il dato dall'assistente dovrai scrivere :> dammi [nome dati].
    Dopo l'addestramento al punto 4, per chiedere di aprire il link dovrai scrivere :> apri [nome link].
    Ma possiamo fare di meglio: a questo scopo myAssistente è compatibile con il linguaggio AIML.

Schermata di benvenuto


1) Area per cambiare lingua.
Se la lingua non è corretta all’avvio, cambiala usando i pulsanti in basso a destra.
NOTA: le lingue presenti nella cartella _dati sono rilevate automaticamente. Il programma si avvia con l’ultima lingua selezionata.

2) Area per inserire comandi. Premendo il microfono puoi usare i comandi vocali.
Nota: lo STT (Speech to Text) utilizza le API Google, e l’audio sarà inviato a Google. Per la massima privacy non premere il microfono: usa solo i comandi testuali.

3) Area dei pulsanti comando. Se conosci già i comandi, chiudi questa barra laterale usando la freccia in basso a destra, accanto all’altoparlante.

4) Area delle risposte dell’assistente. Le risposte saranno mostrate qui e lette ad alta voce quando l’audio è attivo. Per interrompere la lettura, inserisci il comando ok o premi il pulsante negli SHORTCUT: “Quiet please”.

5) Area controllo privacy
In alto a sinistra trovate l'indicatore sorgente delle risposte. Per essere sempre in controllo della vostra privacy.

Oltre a quando appare il bollino 🔴 rosso di avvertimento, sono sempre inviati all'esterno (Google speech API) i vostri comandi vocali senza avvertimento, per essere convertiti in testo. Per privacy 100% non usare la funzione microfono e non abilitare API per IA.

🟢 verde - memory: risposta ottenuta internamente da memory.json
🔵 blu - AIML: risposta ottenuta internamente dai file aiml/langXX/[file].aiml
🔴 rosso - AI: risposta ottenuta da IA esterna
⚫ grigio: messaggi di sistema

Priorità nella ricerca delle risposte:
1) ⚫ grigio: Parole di stop TTS
2) ⚫ grigio: Stati di dialogo attivi
3) 🟢 verde: Risposte fisse — da config.json
4) 🟢 verde: Comandi — da memory.json
5) 🔵 blu: AIML — da file .aiml
6) 🔴 rosso: AI esterna
7) ⚫ grigio: _non_capito()

Shortcut


Cliccando la freccia in basso a sinistra di SHORTCUT puoi aprire/chiudere il pannello dei comandi rapidi personalizzati.
Tutti i pulsanti in quest’area sono personalizzabili. Per dettagli, consulta il (2) Manuale utente.

Comandi predefiniti

ComandoDescrizione (lang_en.json)
trova... <name>Trova i dati in memoria
apri... <name>Apre file, cartelle o programmi
cerca... <query>Cerca nella memoria
cerca media <query>Cerca immagini, musica e video nella cartella _dati/asset
elenca memoriaMostra tutte le voci in memoria
configuraConfigura il file config.json
aiutoElenca i comandi disponibili
esciChiude il programma myAssistente
--- GESTIONE MEMORIA ---
imparaInserimento guidato
ricorda... <name> <data>Salva informazioni in memoria
ricorda immagine <name> <data>Salva immagini in memoria
modifica... <name>Modifica una voce
cancella... <name>Cancella una voce
copia... <name>Copia una voce negli appunti
SHORTCUT
elenco comandi rapidi
LINGUA
nome o codice lingua <code>Cambia lingua
Nota Tutti i nomi dei comandi e dei pulsanti nella finestra dell'assistente sono personalizzabili nel file config.json. Per ogni comando puoi definire più parole alternative. Per maggiori informazioni leggi (4) Manuale configurazione.
