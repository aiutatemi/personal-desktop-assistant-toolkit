(7) Manuale AIML

  • Scopo: In questo manuale trovi come configurare i file AIML standard per myAssistente.
  • Prerequisiti: L’eseguibile di myAssistente per il tuo sistema operativo,
    oppure, in alternativa, i file Python myAssistente.py (opzionale per usare il linguaggio AIML) e aiml_parser.py, con Python installato sulla tua macchina (multipiattaforma).
  • Riferimenti: (1) Manuale installazione, (2) Manuale utente, (4) Manuale configurazione, (5) Manuale configurazione memoria, (6) Manuale configurazione lingue.
Nei pacchetti di distribuzione potrebbero essere presenti alcuni file AIML. Assicurati che si trovino nella cartella corrispondente alla tua lingua. Esempio: per l’italiano, i file devono essere in _dati/aiml/IT/. Puoi anche scaricarne altri dalla rete: il sistema è compatibile con lo standard AIML.

I nomi di tutti i comandi possono essere modificati nel file lang_XX.json e potrebbero quindi differire da quelli indicati in questo manuale. Per i dettagli, fai riferimento al (4) Manuale configurazione.

📁 Dove sono collocati i file

I file trattati in questo manuale si trovano all’interno della cartella _dati/aiml/.

  • Una sotto-cartella per ogni lingua: _dati/aiml/[LANG]/. Esempio: la lingua italiana carica tutti i file AIML presenti in _dati/aiml/IT/.

Che cos’è AIML, in due righe

AIML è un linguaggio basato su regole. Ogni regola stabilisce:

  • Quando l’utente scrive X → rispondi Y.

Ogni regola è una categoria, composta da due parti:

  • <pattern>: ciò che deve scrivere l’utente
  • <template>: la risposta del bot
<category>
    <pattern>CIAO</pattern>
    <template>Ciao!</template>
</category>

AIML è uno standard consolidato, utilizzato dai primi chatbot diffusi in rete. Puoi trovare file AIML pronti online e alcuni sono disponibili anche nel repository del progetto myAssistente.

Potenzia la comprensione

Come configurarli per myAssistente.
I file AIML per la lingua italiana si trovano nella cartella _dati/aiml/IT/. Crea un nuovo file (esempio: myassistente.aiml) con una struttura simile alla seguente.

<?xml version="1.0" encoding="UTF-8"?>

<aiml>

<category>
    <pattern>* APRI * POSTA *</pattern>
    <template avatar="positivo" comando="apri posta">Apro la posta!</template>
</category>

<category>
    <pattern>PUOI APRIRE IL PROGRAMMA DI POSTA</pattern>
    <template><srai>APRI POSTA</srai></template>
</category>

</aiml>

asterischi * sono caratteri jolly: corrispondono a qualsiasi sequenza di parole. Nel nostro esempio, qualsiasi parola prima e dopo APRI e qualsiasi parola dopo POSTA verrà accettata. Nota: lo standard AIML converte automaticamente in maiuscolo tutte le frasi dell’utente.

All’interno del tag <template> trovi due attributi specifici di myAssistente:

  • avatar="positivo" — opzionale, indica quale immagine mostrare a schermo
  • comando="apri posta" — fondamentale, è il comando che l’assistente eseguirà

Il tag <srai> è utilissimo per evitare duplicazioni: converte una frase dell’utente in un’altra già gestita. Nell’esempio, scrivendo puoi aprire il programma di posta, il testo viene trasformato in APRI POSTA e gestito dalla categoria precedente.

NOTA: Gli attributi avatar e comando sono riconosciuti solo da myAssistente. Se usi questi file con altri motori AIML, le categorie funzioneranno comunque, ma gli attributi verranno ignorati.

Puoi anche rendere la risposta casuale tra più alternative:

<category>
    <pattern>* APRI * POSTA *</pattern>
    <template avatar="positivo" comando="apri posta">
        <random>
            <li>Apro la posta per te!</li>
            <li>Ecco la posta di oggi.</li>
            <li>Aperta! Stiamo aspettando dei messaggi?</li>
        </random>
    </template>
</category>
Esiste una vasta documentazione AIML online, utile per approfondire.

Esempio generico per un comando associato a un nome:

<category>
    <pattern>* APRIRE * POSTA *</pattern>
    <template><srai>APRI POSTA</srai></template>
</category>

Con questa configurazione, l’assistente aprirà la posta con quasi tutte le frasi possibili. Per una copertura migliore, adatta i pattern al tuo modo di parlare.
