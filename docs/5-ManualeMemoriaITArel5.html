(5) Manuale della memoria

  • Scopo: In questo manuale trovi come configurare la memoria di myAssistente per sfruttare al meglio le sue potenzialità.
  • Prerequisiti: L’eseguibile di myAssistente per il tuo sistema operativo,
    oppure, in alternativa, i file Python myAssistente.py e (opzionale, per usare il linguaggio AIML) aiml_parser.py, con Python installato sulla tua macchina (multipiattaforma).
  • Riferimenti: (1) Manuale installazione, (2) Manuale utente, (4) Manuale configurazione.

I nomi di tutti i comandi possono essere modificati nel file lang_XX.json; potrebbero quindi essere diversi da quelli indicati in questo manuale. Per i dettagli, consulta il (4) Manuale configurazione.

📁 Dove sono collocati i file

Il file trattato in questo manuale si trova all’interno della cartella _dati/.

  • _dati/memory.json: Dati memorizzati.

File memory.json

Nota: Se il file memory.json è mancante, il sistema avviserà l’utente e genererà un nuovo file vuoto al primo inserimento di dati tramite interfaccia. Se il file è presente ma corrotto, verrà rinominato in memory.json.bak per non perdere gli eventuali dati validi, e ne verrà creato uno nuovo.

L’inserimento dei dati in memoria può essere effettuato direttamente dall’interfaccia utente di myAssistente usando i comandi ricorda e impara. Consulta il (2) Manuale utente per le istruzioni.

Puoi modificare o aggiungere dati anche manualmente. Apri il file con un editor di testo:

Memorizzare un dato

{
    "nome": "Codice",
    "alias": "tasse",
    "soggetto": "Emanuele",
    "dati": "CDFTSS99T30L424X",
    "tag": "codici",
    "avatar": "magazziniere"
},

nome — campo obbligatorio, contiene il termine da usare per richiedere il dato all’assistente.
alias — campo opzionale, contiene termini alternativi al nome per richiedere lo stesso dato.
soggetto — campo opzionale, indica il proprietario del dato, utile per memorizzare dati di persone diverse.
dati — campo obbligatorio, contiene il valore del dato.
tag — campo opzionale, utile per la ricerca, chiedendo all’assistente cerca codici troverà tutti i dati con quel tag.
avatar — campo opzionale, indica quale immagine l’assistente deve mostrare quando visualizza il dato. Se non indicato, il sistema sceglie un’immagine casuale secondo la configurazione nel file config.json (vedi (4) Manuale configurazione).

Comando per recuperare l’informazione: trova [nome] oppure dimmi [nome].

Memorizzare un link

Scrivendo un link nel campo "dati", il sistema lo riconoscerà automaticamente.

{
    "nome": "Python",
    "alias": "progetti",
    "soggetto": "aprire una cartella",
    "dati": "C:\\Python\\Progetti\\",
    "tag": "cartelle",
    "avatar": "informatica"
},

Il file JSON necessita di backslash doppi per l’esempio C:\\Python\\Progetti\\, ma l’assistente lo mostrerà correttamente e lo aprirà senza problemi.

Per aprire la cartella: apri [nome].

Memorizzare un sito web

Allo stesso modo, si può memorizzare un sito web.

{
    "nome": "Autore",
    "alias": "Cassani",
    "soggetto": "Emanuele",
    "dati": "https://www.steppa.net/cassani/index.htm",
    "tag": "web",
    "avatar": "agenda"
},

Gli slash normali / non richiedono escape. Scrivi semplicemente l’indirizzo web e l’assistente lo aprirà nel browser.

Per aprire il sito: apri [nome].

Memorizzare un programma

Puoi memorizzare anche un programma da eseguire.

{
    "nome": "browser",
    "alias": "web",
    "soggetto": "brave",
    "dati": "C:\\Program Files\\BraveSoftware\\Brave-Browser\\Application\\brave.exe",
    "tag": "programmi",
    "avatar": "bibliotecaria"
},

Inserisci nel campo dati il percorso dell’eseguibile. Lo stesso procedimento vale per programmi, cartelle e file.

Comando per lanciare il programma: apri [nome].

Memorizzare qualsiasi cosa

Fai delle prove con tutto ciò che ti viene in mente: l’assistente funziona in modo estremamente flessibile.

{
    "nome": "shell",
    "alias": "prompt",
    "soggetto": "Windows11",
    "dati": "cmd.exe",
    "tag": "comandi",
    "avatar": "informatica"
},

Esempio con un comando Windows che apre il prompt dei comandi.

Comando per lanciare il comando: apri shell.
