(2) Manuale utente

  • Scopo: Questo manuale ti guida nella configurazione personale di myAssistente.
  • Prerequisiti: myAssistente5 installato.
  • Riferimenti: (1) Manuale installazione.
Installazione Devi ancora installare myAssistente? Ci sono dei pacchetti pronti per utenti Windows e Linux: basta scaricare, decomprimere un archivio ZIP e cliccare sull'eseguibile. per sorgente Python e per creare paccherro macOS Leggi il (1) Manuale installazione.

Sono alla ricera continua di nuove idee utili da implementare, qualsiasi suggerimento è benvenuto.

📚 Per leggere i manuali, usa il comando manuali e myAssistente aprirà la pagina con l'indice della documentazione disponibile.

Configura nomi utente e assistente

All'inzio l'assistente si chiama Assistant e l'utente user, per cambiarli scrivi oppure premi il microfono e pronuncia:

[23:09] user:> configura breve
[23:09] Assistant:> Cambia il mio nome: nome_avatar valore attuale = 'Assistant'
Inserisci un nome o lascia vuoto per annullare
[23:09] user:> Alice
[23:09] Alice:> Parametro 'nome_avatar' aggiornato a 'Alice'
[23:09] Alice:> Cambia il tuo nome: nome_utente valore attuale = 'user'
Inserisci un nome o lascia vuoto per annullare
[23:09] user:> Emanuele
[23:09] Alice:> Parametro 'nome_utente' aggiornato a 'Emanuele'
[23:09] Alice:> Configurazione completata.
[23:09] Emanuele:>

Ricorda e impara

Per far ricordare un dato all'assistente, usa i comandi ricorda (per una voce) o impara (per più voci), scrivi oppure premi il microfono e pronuncia:

[20:53] Emanuele:> ricorda
[20:53] Alice:> Dimmi il nome che devo registrare:
[20:53] Emanuele:> IMPORTANTE
[20:54] Alice:> Bene, dimmi i dati da ricordare per 'IMPORTANTE':
[20:55] Emanuele:> devo ricordare 348 966 111
[20:53] Alice:> Fatto! 'IMPORTANTE' salvato in memoria.

[20:55] Emanuele:> dimmi IMPORTANTE
[20:55] Alice:> I dati di 'IMPORTANTE' (Emanuele):
  devo ricordare 348 966 111

Per recuperare il dato basterà chiedere :>trova importante (o dimmi)

Comando veloce per memorizzare sino a due perole dopo il nome:

[20:53] Emanuele:> ricorda telefono marta 345
[20:52] Alice:> Fatto! 'telefono' salvato in memoria.

La prima parola sarà il nome, le altre due il dato.

Si usa impara o apprendi per memorizzare molti dati di seguito

[21:04] Emanuele:> impara
[21:04] Alice:> Inserimento guidato — ti chiedo un campo alla volta.
Scrivi 'salta' per i campi opzionali, 'fine' per annullare.

Nome (obbligatorio):
[21:04] Emanuele:> Codice fiscale
[21:04] Alice:> Alias / abbreviazione (opzionale — scrivi 'salta' per saltare):
[21:04] Emanuele:> salta
[21:04] Alice:> Intestatario (opzionale — scrivi 'salta' per usare il tuo nome):
[21:05] Emanuele:> salta
[21:05] Alice:> Dati da memorizzare (obbligatorio):
[21:05] Emanuele:> CDCFSC65T30...
[21:05] Alice:> Tag (opzionale — es: famiglia, lavoro — scrivi 'salta' per saltare):
[21:05] Emanuele:> agenzia entrate
[21:05] Alice:> Avatar (opzionale — scrivi 'salta' per 'sorridente'):
  sorridente · soddisfatto · triste · bibliotecaria · magazziniere · benvenuto
[21:05] Emanuele:> triste
[21:05] Alice:> Salvato! 'Codice fiscale' in memoria.
Desideri inserire un altro elemento? (sì / no)
[21:05] Emanuele:> s

[21:05] Alice:> Inserimento guidato — ti chiedo un campo alla volta.
Scrivi 'salta' per i campi opzionali, 'fine' per annullare.
Nome (obbligatorio):
[21:06] Emanuele:> Codice fiscale
[21:06] Alice:> Alias / abbreviazione (opzionale — scrivi 'salta' per saltare):
[21:06] Emanuele:> salta
[21:06] Alice:> Intestatario (opzionale — scrivi 'salta' per usare il tuo nome):
[21:06] Emanuele:> Andrea
[21:06] Alice:> Dati da memorizzare (obbligatorio):
[21:06] Emanuele:> NDRFCL89T30...
[21:06] Alice:> Tag (opzionale — es: famiglia, lavoro — scrivi 'salta' per saltare):
[21:06] Emanuele:> Agenzia entrate
[21:06] Alice:> Avatar (opzionale — scrivi 'salta' per 'sorridente'):
  sorridente · soddisfatto · triste · bibliotecaria · magazziniere · benvenuto
[21:06] Emanuele:> triste
[21:06] Alice:> Salvato! 'Codice fiscale' in memoria.

Desideri inserire un altro elemento? (sì / no)
[21:06] Emanuele:> no
[21:06] Alice:> Inserimento completato.

In questo esempio, ho inserito due dati dallo stesso nome codice fiscale uno di Emanuele e uno di Andrea.

Per far aprire un link a un sito web dall'assistente, scrivi oppure premi il microfono e pronuncia:

[21:12] Emanuele:> ricorda
[21:12] Alice:> Dimmi il nome che devo registrare:
[21:12] Emanuele:> Sito web
[21:12] Alice:> Bene, dimmi i dati da ricordare per 'Sito web':
[21:12] Emanuele:> https://www.steppa.net/cassani/
[21:12] Alice:> Fatto! 'Sito web' salvato in memoria.

[21:30] Emanuele:> apri il Sito web
Alice:> Apro subito: https://www.steppa.net/cassani/

Per far aprire un link a un file, una cartella:

[21:12] Emanuele:> ricorda
[21:12] Alice:> Dimmi il nome che devo registrare:
[21:12] Emanuele:> Link a file
[21:12] Alice:> Bene, dimmi i dati da ricordare per 'Link a file':
[21:12] Emanuele:> C:\Users\emanuele\Desktop\documento.rtf
[21:12] Alice:> Fatto! 'Link a file' salvato in memoria.

[21:30] Emanuele:> apri il link a file
Alice:> Apro subito: C:\\Users\\emanuele\\Desktop\\documento.rtf

Il file sarà aperto col programma associato dal tuo sistema operativo, nota che i backslash \ sono in memoria raddoppati per una necessità del linguaggio JSON, ma l'assistente lo gestirà per te.

Si può addestrare anche per aprire un qualsiasi programma:
Esempio dato da inserire: C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe
Qualsiasi cartella:
Esempio: C:\Users\emanuele\Desktop\ apre il desktop
Oppure anche funzioni di sistema. Esempio per gli utenti Windows: inserire control per aprire il pannello di controllo, oppure cmd.exe per lanciare il prompt dei comandi.
Prova con qualsiasi cosa ti venga in mente, probabilmente funzionarà

Nota Si possono effettuare le stesse configurazioni modificando il file _memory.json con un semplice editor di testo come Notepad, vedi (4) Manuale configurazione.

I comandi ricorda immagine oppure memorizza immagine servono a salvare nei dati di myAssistente, un'immagine.

[11:21] Emanuele:> ricorda questa immagine
 --- si apre una finestra per selezionare un'immagine---
[11:22] Alice:> Dimmi quale nome associare all'immagine
[11:22] Emanuele:> icona
[11:22] Alice:> Quale descrizione (tag) vuoi aggiungere?
[11:22] Emanuele:> usata per myAssistente
[11:22] Alice:> Fatto! Immagine 'icona' salvata in memoria.

Il file sarà memorizzato nella cartella _dati/asset/ e potrai recuperala col comando apri [nome]
Nell'esempio sopra apri icona lancerà il programma associato a quel tipo di file.

Modifica

Usa il comando modifica o cambia per modificare un dato in memoria.

[17:13] Emanuele:> cambia TEST
[17:13] Alice:> Voce trovata:
  nome: TEST
  soggetto: Emanuele
  contenuto da modificare
  [avatar: coniglio]
Quale campo vuoi modificare?
Puoi scrivere solo il campo (es: 'dati') oppure campo e valore (es: 'dati CSSMNL...')
[17:14] Emanuele:> dati diverso
[17:14] Alice:> Modificato! 'dati' aggiornato a: diverso

Copia

Usa il comando copia o duplica per copiare il dato negli appunti per poi incollarlo dove ti serve.

[01:19] Emanuele:> duplica codice fiscale
[01:19] Alice:> Copiato negli appunti:
  CDCFSC65T30...

Ricorda: risposte fisse

Inoltre, modificando i parametri che seguono, dentro al file _dati/config.json con un semplice editor di testo come Notepad), si possono preconfigurare anche delle risposte fisse opzionali, per specifici input dell'utente. Vedi (4) Manuale configurazione.

Richiamare i dati

Come richiedere i dati memorizzati e come far aprire link a cartelle, file e siti web.

Cerca

Abbiamo già: accennato i comandi trova e apri. Con cerca si troveranno tutti i nomi, alias e dati che contengono la parola richiesta.

[15:19] Emanuele:> cerca codice fiscale
[15:19] Alice:> Ho trovato 2 risultato/i per 'codice fiscale':
[1]   nome: Codice fiscale
  alias: 
  soggetto: Emanuele
  CDCFSC65T30...
  tag: agenzia entrate
  [avatar: triste]
[2]   nome: Codice fiscale
  alias: 
  soggetto: Andrea
  NDRFCL89T30...
  tag: agenzia entrate
  [avatar: triste]

Elenca

Per visualizzare tutto il contenuto della memoria, basta usare il comando elenca oppure lista. Quando la lista è troppo lunga, potere mettere a tacere l'assistente col comando ok (pulsante nei shortcut Ho capito se configurato.

[15:26] Emanuele:> elenca
[15:26] Alice:> Ho 4 voce/i in memoria:
  1. Codice fiscale [] — Emanuele
  2. Codice fiscale [] — Andrea
  3. Posta [mail] — Emanuele
  4. estratto conto [ec] — foglio calcolo apribile
...

Cancella

Per cancellare un dato in memoria, basta usare il comando cancella e il nome del dato da cancellare (se non ricordi il nome esatto, puoi usare prima il comando elenca

[16:38] Emanuele:> cancella TEST
[16:38] Alice:> Vuoi davvero eliminare:
  nome: TEST
  soggetto: Emanuele
  123 e altro
  [avatar: sorridente]
Digita 'sì' per confermare o 'no' per annullare.
[16:38] Emanuele:> s
[16:38] Alice:> 'TEST' eliminato dalla memoria.
Nota L'assitente lavora con comandi fissi. Supponendo di avere in memoria un ricordo dal titolo posta che come dati ha il link all'eseguibile al programma di posta Outlook, chiedere :>Apri il link della posta non funionerà:, perché: l'assistente si aspetta apri posta. Per potenziare la sua capacità di comprensione, ho integrato la compatibilità con il linguaggio AIML. Vedi (7) Manuale AIML.

MyAgenda, myNote, MyTodo

L'assistente scambia informazioni con le miniApp integrate MyAgenda, myNote, MyTodo.

Cliccando sui pulsanti a destra nella sezione SHORTCUT si apre la finestra del tool.
Le mini app tutelano la privacy a 100% e le informazoni rimangono nella memoria del browser locale, per condividerle con myAssistente, cliccare il pulsante Salva per myAssitente. La prima volta si aprira' una finestra per selezionare dove salvare le informaizoni.

Importante L'assistente le trova solo se inserite nela cartella: ./myAssistente/_dati/plugins/
