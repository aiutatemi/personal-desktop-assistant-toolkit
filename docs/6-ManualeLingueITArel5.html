(6) Manuale configurazione lingue

In questo manuale trovi come configurare la lingua di myAssistente per sfruttarne al meglio le potenzialità. Nei pacchetti di distribuzione sono sempre presenti le lingue italiano e inglese, ma è possibile aggiungerne altre scaricando i file già pronti dal repository del progetto.

  • Scopo: In questo manuale scoprirai come aggiungere una nuova lingua o modificarne una esistente.
  • Prerequisiti: L’eseguibile di myAssistente per il tuo sistema operativo,
    oppure, in alternativa, i file Python myAssistente.py e (opzionale, per usare il linguaggio AIML) aiml_parser.py, con Python installato sulla tua macchina (multipiattaforma).
  • Riferimenti: (1) Manuale installazione, (2) Manuale utente, (4) Manuale configurazione, (5) Manuale configurazione memoria.
Nei pacchetti di distribuzione sono sempre incluse le lingue italiano e inglese. Puoi aggiungerne altre traducendo i file o scaricandoli dal repository del progetto.

I nomi di tutti i comandi possono essere modificati nel file lang_XX.json e potrebbero quindi differire da quelli indicati in questo manuale. Per i dettagli, fai riferimento al (4) Manuale configurazione.

📁 Dove sono collocati i file

I file trattati in questo manuale si trovano all’interno della cartella _dati/.

  • _dati/lang_*.json: File di localizzazione.

File lang.json

Nota: Se il sistema non trova alcun file lang_XX.json, verrà utilizzata la lingua predefinita: italiano.

In caso di cambio lingua, il sistema memorizza l’informazione in config.json e salva un backup della configurazione precedente in config.json.bak.

La scelta della lingua può essere effettuata direttamente dall’interfaccia utente di myAssistente tramite i pulsanti sotto la voce Lingua. Il sistema rileva automaticamente le lingue presenti nella cartella _dati/ e le rende selezionabili.

Nome dei file: lang[CODE].json, dove [CODE] è il codice standard della lingua. Esempi: langIT.json, langEN.json, langDE.json. All’interno di questi file puoi configurare tutti i termini. Aprili con un editor di testo.

Prima parte: Lingua per il riconoscimento vocale

  "lingua_stt": "it-IT",

Si tratta della lingua usata dall’assistente per la pronuncia e il riconoscimento vocale tramite Google Speech. È importante specificare anche la regione (esempio: en-GB o en-US). La stessa informazione è presente anche nel file config.json, utilizzata dal sistema nel caso non venga trovato alcun file di lingua.

Seconda parte: I nomi dei comandi

  "alias_comandi": {
    "dammi":    ["trova", "dimmi", "mostrami", "visualizza"],
    "apri":     ["apri", "lancia", "avvia", "esegui", "metti"],
    "cerca":    ["cerca", "ricerca"],
    "elenca":   ["elenca", "lista", "mostra tutto"],
    "configura":["configura", "impostazioni", "settings", "preferenze"],
    "aiuto":    ["aiuto", "help", "comandi"],
    "esci":     ["esci", "chiudi", "arrivederci", "quit", "exit"],
    "impara":   ["impara", "apprendi", "inserisci"],
    "ricorda":  ["ricorda", "memorizza", "salva"],
    "modifica": ["modifica", "cambia", "aggiorna"],
    "elimina":  ["cancella", "rimuovi"],
    "copia":    ["copia", "duplica", "copy"]
  },

A sinistra trovi il nome di sistema, mentre a destra i nomi che vuoi far apparire cliccando il pulsante nell’interfaccia utente. Il nome di sistema in italiano continuerà sempre a funzionare: i nomi che inserisci sono alternative aggiuntive.

Puoi indicare più nomi per lo stesso comando oppure lasciarne nessuno (esempio: "esci": []). Se per errore duplichi un nome, verrà considerato solo il primo.

Terza parte: I nomi nell’interfaccia utente

  "titolo_finestra":  "Assistente – {nome_avatar}",

  "label_comandi":        "COMANDI",
  "panel_dammi":          "trova...",
  "panel_apri":           "apri...",
  "panel_cerca":          "cerca...",
  "panel_media":          "cerca media",
  "panel_elenca":         "elenca memoria",
  "panel_configura":      "configura",
  "panel_aiuto":          "aiuto",
  "panel_esci":           "esci",

  "panel_sep_memoria":    "── GESTISCI MEMORIA ──",
  "panel_impara":         "impara",
  "panel_ricorda":        "ricorda...",
  "panel_ricorda_img":    "ricorda immagine",
  "panel_modifica":       "modifica...",
  "panel_elimina":        "cancella...",
  "panel_copia":          "copia...",

  "label_shortcut":       "SHORTCUT",
  "label_lingua":         "LINGUA",
  "btn_invia":            "Invia",

Qui trovi tutti i testi e le etichette presenti nell’interfaccia di myAssistente. Importante: se cambi il nome di un pulsante, cliccandolo apparirà comunque il primo comando configurato nella sezione alias_comandi. Se vuoi che corrispondano, usa lo stesso termine.

Esempio comando:

  "alias_comandi": {
    "dammi": ["dimmi", "mostrami", "visualizza"]
  },

Esempio pulsante corrispondente:

  "panel_dammi": "dammi..."

In questo caso, il pulsante mostrerà dammi..., ma nella finestra di dialogo apparirà dimmi.

Quarta parte: Le esclusioni

Questi articoli servono per essere esclusi dalla frase dell’utente, così da permettere al sistema di riconoscere correttamente i comandi. 

  "articoli": [
    "il", "lo", "la", "i", "gli", "le", "un", "una", "uno",
    "del", "della", "dei", "degli", "delle", "al", "allo",
    "alla", "ai", "agli", "alle", "dal", "dallo", "dalla",
    "dai", "dagli", "dalle", "col", "coi", "su", "per", "con"
  ],

Esempio: Apri la posta. Se non configurato diversamente in altri file (vedi (7) Manuale AIML), il comando non sarebbe riconosciuto. Con questa lista, l’articolo la viene ignorato e il comando diventa semplicemente apri posta.

Ultima parte: Localizza le frasi

Qui puoi configurare tutte le frasi usate dal programma. Ricorda: devi modificare solo i valori a destra, mentre le chiavi a sinistra non vanno mai cambiate. 

  "aiuto_testo": "Ecco quello che posso fare per te:\n\ntrova\n..."

Se devi andare a capo, usa \n e non andare a capo manualmente.

Basta una virgola errata e il file .json smette di funzionare. Se hai Python installato, puoi verificarlo con: 

python -m json.tool lang_it.json

In alternativa, puoi farlo controllare a un’IA chiedendo semplicemente: 

Controlla questo file JSON, sistema eventuali errori e ridammelo
