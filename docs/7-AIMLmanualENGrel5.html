(7) AIML Manual

  • Purpose: This manual explains how to configure the standard AIML files used by myAssistente.
  • Prerequisites: The myAssistente executable for your operating system,
    or alternatively the Python files myAssistente.py (optional for AIML support) and aiml_parser.py, with Python installed on your machine (multiplatform).
  • References: (1) Installation Manual, (2) User Manual, (4) Configuration Manual, (5) Memory Configuration Manual, (6) Language Configuration Manual.
Some AIML files may already be included in the distribution packages. Make sure they are placed in the folder corresponding to your language. Example: for Italian, files must be inside _dati/aiml/IT/. You can also download additional AIML files from the web: the system is compatible with the standard AIML format.

All command names can be customized in the lang_XX.json file and may therefore differ from those shown in this manual. For details, refer to the (4) Configuration Manual.

📁 File locations

The files described in this manual are located inside the _dati/aiml/ folder.

  • One subfolder per language: _dati/aiml/[LANG]/. Example: the Italian version loads all AIML files found in _dati/aiml/IT/.

What AIML is, in two lines

AIML is a rule‑based language. Each rule states:

  • When the user writes X → reply Y.

Each rule is a category composed of two parts:

  • <pattern>: what the user must write
  • <template>: what the bot replies
<category>
    <pattern>CIAO</pattern>
    <template>Hello!</template>
</category>

AIML is a well‑established standard, originally used by early chatbots. You can find ready‑made AIML files online, and some are also available in the myAssistente project repository.

Enhance understanding

How to configure AIML files for myAssistente.
AIML files for the Italian language are located in _dati/aiml/IT/. Create a new file (e.g., myassistente.aiml) with a structure like the following.

<?xml version="1.0" encoding="UTF-8"?>

<aiml>

<category>
    <pattern>* OPEN * MAIL *</pattern>
    <template avatar="positivo" comando="open mail">Opening your mail!</template>
</category>

<category>
    <pattern>CAN YOU OPEN THE MAIL PROGRAM</pattern>
    <template>OPEN MAIL</srai></template>
</category>

</aiml>

Asterisks * are wildcards: they match any sequence of words. In this example, any words before and after OPEN and any words after MAIL will be accepted. Note: the AIML standard automatically converts all user input to uppercase.

Inside the <template> tag you will find two attributes specific to myAssistente:

  • avatar="positivo" — optional, selects the avatar image to display
  • comando="open mail" — essential, this is the command executed by the assistant

The <srai> tag is extremely useful to avoid repeating rules: it converts a user sentence into another one already handled. In the example, writing can you open the mail program? becomes OPEN MAIL, triggering the previous category.

NOTE: The avatar and comando attributes are recognized only by myAssistente.
If you use these AIML files with other engines, the categories will still work, but these attributes will be ignored.

You can also randomize the response:

<category>
    <pattern>* OPEN * MAIL *</pattern>
    <template avatar="positivo" comando="open mail">
        <random>
            <li>Opening your mail!</li>
            <li>Here is today’s mail.</li>
            <li>Done! Waiting for new messages?</li>
        </random>
    </template>
</category>
There is extensive AIML documentation available online.

Generic example for a command associated with a name:

<category>
    <pattern>* OPEN * MAIL *</pattern>
    <template>OPEN MAIL</srai></template>
</category>

With this configuration, the assistant will open the mail for almost any phrasing. For better coverage, adapt the patterns to your own speaking style.
