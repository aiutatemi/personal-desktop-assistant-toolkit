(3) Plugin Manual

  • Purpose: This manual guides you through the use of the mini Apps included as plugins in myAssistente.
  • Requirements: A working installation of myAssistente.
  • Sections: myAgenda, myTodo, myNote

The plugins originate from standalone mini Apps designed to provide basic services with full privacy protection, running locally with no registration required. You can find more on the website www.steppa.net/cassani.

The files required for execution are HTML files located in _dati/asset/plugin/, while the data shared with myAssistente is stored in .json format inside _dati/plugins/.

myAssistente loads all .json files saved by the plugins from the _dati/plugins/ folder at startup. They can be accessed from memory using the commands find or list memory.

myAgenda

The myAgenda application is included in myAssistente and can be launched with the command open myAgenda or by clicking the corresponding button under SHORTCUT.


Navigate between months using the arrows at the top. A dot marks the current day; colored days indicate that a note is present; a day crossed with an X means the event has been completed.
Hover over a day to preview the event, and click it to add/edit data or to delete/complete it:

Under Recurrence you can choose whether the event repeats This year only or Every year. NOTE: when marking an event as completed (V), it is important to specify whether it is completed This year only or Every year from now on.

Click Settings to open the configuration screen.

In Color labels you can customize the colored headers assigned to different events. In Data management (backup) you can save data for myAssistente or perform a local backup/restore.

Important
To ensure 100% privacy, myAgenda data is stored exclusively in the browser’s local memory. If you clear the browser data or use a different browser, the only way to recover your information is through the Restore backup function.
When using Save for myAssistente, make sure to save the memory file to _dati/plugins/myAgenda.json, the only folder read by myAssistente at startup.

myTodo

The myTodo application is included in myAssistente and can be launched with the command open myTodo or by clicking the corresponding button under SHORTCUT.


The list of tasks will appear.
On the left are past/overdue tasks; on the right, upcoming tasks that are still pending.
The buttons work similarly to those in the other mini Apps.

Important
To ensure 100% privacy, myTodo data is also stored exclusively in the browser’s local memory. If you clear the browser data or use another browser, the only way to recover your tasks is through the Restore backup function.
When using Save for myAssistente, make sure to save the memory file to _dati/plugins/myTodo.json, the only folder read by myAssistente at startup.

Click the pencil icon to edit a task or the trash icon to delete it.

From the window that appears, you can edit all task details. Using Recurrence, a task can be set as one-time or repeating.

myNote

The myNote application is included in myAssistente and can be launched with the command open myNote or by clicking the corresponding button under SHORTCUT.

Your notes will appear (they can be moved by clicking and dragging them).
To add a new note, click +.

The note text supports optional HTML formatting. You can use the toolbar above the input area to apply formatting.
Useful options:

  • Link: Write text in the note, select it, and click the link icon. A window will appear where you can enter a URL, and the selected text will become clickable.
  • Copy to clipboard: Write text in the note, select it, and click the notepad icon. The selected word/phrase becomes clickable, and clicking it will copy the text to the clipboard (useful for copying addresses or complex passwords).
Important
To ensure 100% privacy, myNote data is also stored exclusively in the browser’s local memory. If you clear the browser data or use another browser, the only way to recover your notes is through the Restore backup function.
When using Save for myAssistente, make sure to save the memory file to _dati/plugins/myNote.json, the only folder read by myAssistente at startup.
