Active Project on GitLab GitLAB Project Documentation

myAssistente is a project designed to give users back control over their data. Unlike commercial cloud assistants, it runs entirely on your computer, ensuring that your information never leaves your hard drive.

Get started in 2 minutes — no account, no cloud, no installation procedure required (download, unzip, run).

✨ Why Choose myAssistente?

  • Total Privacy: Local data management through transparent JSON files (except Google Speech-to-Text and optional AI integration).🔒
  • Customization: Fully configurable desktop assistant.
  • Automation: Remember information, store media, open files, folders, programs and websites.
  • Integration: Works with free miniApps: myAgenda, myNote and myTodo.
  • Integration: Optional connection with external AI (API key required).
  • AIML Parser: Full compatibility with AIML 1.x files to personalize the assistant's behaviour and comprehension.
  • Voice or text commands, with multilingual support.
  • Multi-language: Native support for over 15 languages. 🌍

📦 Start myAssistente

Download the latest release and extract the ZIP file (USB drives supported).

myAssistente        ← main folder
    myAssistente.exe  ← (Windows) launch here
    myAssistente      ← (Linux) launch here
    _dati/          ← configurable data folder
        config.json ← configuration
        memory.json ← memory file
        plugins/    ← myAgenda, myNote, myTodo plugins
        aiml/       ← optinal AIML language files
        asset/      ← media storage
	     /avatar  ← avatar images and video
	     /manual  ← myAssistente documentation
	     /plugin  ← plugin Javascript miniApp

macOS, Windows, and Linux (with Python installed): download myAssistente.py and the _dati folder, then run myAssistente.py.
