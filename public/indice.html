Progetto Attivo su GitLab Documentazione Progetto GitLAB

myAssistente è un progetto pensato per restituire agli utenti il controllo sui propri dati. A differenza degli assistenti cloud commerciali, viene eseguito interamente sul tuo computer, garantendo che le tue informazioni non lascino mai il tuo disco rigido.

Inizia in 2 minuti — nessun account, nessun cloud, nessuna procedura di installazione richiesta (scarica, decomprimi, avvia).

✨ Perché scegliere myAssistente?

  • Privacy Totale: Gestione dati locale tramite file JSON trasparenti (eccetto Google Speech-to-Text e integrazione IA opzionale).🔒
  • Personalizzazione: Assistente desktop completamente configurabile.
  • Automazione: Ricorda informazioni, archivia media, apre file, cartelle, programmi e siti web.
  • Integrazione: Funziona con miniApp gratuite: myAgenda, myNote e myTodo.
  • Integrazione: Connessione opzionale con IA esterne (richiesta chiave API).
  • Parser AIML: Piena compatibilità con i file AIML 1.x per personalizzare il comportamento e la comprensione dell'assistente.
  • Comandi vocali o testuali, con supporto multilingua.
  • Multi-lingua: Supporto nativo per oltre 15 lingue. 🌍

📦 Avvia myAssistente

Scarica l'ultima versione ed estrai il file ZIP (supporta anche chiavette USB).

myAssistente        ← cartella principale
    myAssistente.exe  ← (Windows) avvia qui
    myAssistente      ← (Linux) avvia qui
    _dati/          ← cartella dati configurabili
        config.json ← configurazione
        memory.json ← file memoria
        plugins/    ← plugin myAgenda, myNote, myTodo
        aiml/       ← file linguaggio AIML opzionali
        asset/      ← archiviazione media
	     /avatar  ← immagini e video avatar
	     /manual  ← documentazione myAssistente
	     /plugin  ← plugin miniApp Javascript

macOS, Windows e Linux (con Python installato): scarica myAssistente.py e la cartella _dati, quindi avvia myAssistente.py.
